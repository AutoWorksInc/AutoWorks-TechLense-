# Install MekView Alpha on Pixel

Successful develop builds publish an installable debug APK named **MekView-Alpha-debug** as a GitHub Actions artifact.

## Install
1. Open the successful Android Build run in GitHub.
2. Under Artifacts, download **MekView-Alpha-debug**.
3. Extract the downloaded ZIP and open **app-debug.apk** on the Pixel.
4. Android may ask you to allow installs from the app used to open the APK. Enable that permission only for this installation source if you trust it.
5. Install and open **MekView**.

## Alpha test
Use demo data only for the first test. Run Scan Vehicle, start the guided diagnosis, capture a Pixel photo and short video, confirm the evidence appears, confirm the failed component, and prepare the estimate draft.

This is a development/debug build. It is not a production release and should not be used for autonomous repair decisions or real customer records.
